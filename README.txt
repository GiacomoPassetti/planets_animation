The scope of this repo is to generate a cool looking gravitational orbit video animation generator. 
Final result will be an interface that allows to select number of point like entities (planets), their masses and initial positions (nondimensionalized).
From them on an animation simulating their trajectories is displayied to the user, buttons that allow to stop and reset the animation are present as well.
I would like the visuals to be cool, more specifically black background, bright color for the objects and a haze that leaeves a fading trajectory behind them.
